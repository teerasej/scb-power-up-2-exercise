# ก่อนเริ่ม

เราจะสร้าง **Service Request Assistant ตัวเดียว** ด้วย Copilot Studio standard harness และใช้ **CASE-201** ต่อเนื่องทั้งห้า Exercise

## บัญชีและ Environment

- ใช้บัญชีและ Environment ฝึกที่ทีมงานกำหนด มีสิทธิ์สร้างและแก้ไข Agent
- ให้ทีมงานยืนยันสิทธิ์ของ Copilot Studio, Generative AI, file Knowledge, Prompt tool, Agent flow และ Topics รวมถึง capacity ที่ใช้ฝึก
- ก่อน Exercise 4 ต้องมี Office 365 Outlook connection, Exchange mailbox และ approved test inbox ที่ทีมงานอนุญาต การทดสอบ flow อาจส่ง email จริง
- Native Agent flow ไม่ได้ต้องมี Power Automate license แยกเพียงเพราะใช้ flow แต่สิทธิ์และ capacity ที่เกี่ยวข้องยังต้องพร้อม
