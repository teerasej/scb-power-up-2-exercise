# ทดลองบันทึกผลด้วย Test log

Test log เหมือนสมุดจด ตอนเราลองฝึกทำอาหาร: เราตั้งใจให้ออกมาอย่างไร ทำจริงแล้วเป็นอย่างไร และครั้งหน้าจะปรับอะไร ลองบันทึกเพียงหนึ่งสถานการณ์เพื่อให้ทีมอธิบายผลทดสอบได้ชัดเจนครับ

กิจกรรมนี้เป็นตัวอย่างเสริม เลือกใช้กับ use case ของทีมต่อได้ตามต้องการ

## ก่อนเริ่ม

- ใช้ Agent ตัวเดิมจาก Exercise 1 ที่บันทึก Instructions ให้ตอบเป็นภาษาไทยแล้ว
- เตรียม Excel หรือแอปที่เปิดและแก้ไขไฟล์ XLSX ได้
- ใช้สิทธิ์ Copilot Studio และ Environment เดิมตาม [สิ่งที่ต้องเตรียม](/prerequisites) หากยังเข้าใช้งานไม่ได้ ให้ผู้สอนช่วยตรวจสิทธิ์ก่อนทดสอบ

## Practice 1: บันทึกผลทดสอบหนึ่งสถานการณ์

**Primary target:** บันทึกผลจริงใน Test log และอธิบายเหตุผลของสถานะที่เลือกได้

1. ดาวน์โหลด <DownloadFile file="test-log.xlsx">test-log.xlsx</DownloadFile> เปิดไฟล์ แล้วเลือก worksheet `Use Case Log`
2. ดูตัวอย่างแรก **ให้ Agent ตอบเป็นภาษาไทย** ซึ่งเตรียมไว้แล้วในแถว 6 อ่านสามช่องก่อนทดสอบ:
   - `Scenario`: สถานการณ์ที่ต้องการตรวจ — ให้ Agent ตอบเป็นภาษาไทย
   - `Starter Prompts`: ข้อความเริ่มต้นที่ใช้ทดสอบ — ทำอะไรได้บ้าง
   - `Expected Result`: สิ่งที่ควรเกิดขึ้น — Agent ตอบเป็นภาษาไทยและอธิบายขอบเขตงานตาม Instructions ปัจจุบัน
3. เปิด Agent ใน Copilot Studio เริ่ม test session ใหม่ในแผง `Test your agent` แล้วส่งข้อความนี้:

   ```text
   ทำอะไรได้บ้าง
   ```

4. อ่านคำตอบ แล้วกรอก `Actual Result` ด้วยสิ่งที่เกิดขึ้นจริง จะสรุปหรือคัดข้อความสำคัญจากคำตอบก็ได้ ระบุทั้งภาษาที่ใช้และงานที่ Agent บอกว่าช่วยได้
5. เทียบคำตอบกับ `Expected Result` แล้วเลือกจาก dropdown ในช่อง `Status`:
   - `Pass`: คำตอบเป็นภาษาไทย **และ** อธิบายขอบเขตงานตรงกับ Instructions ปัจจุบัน
   - `Failed`: ไม่ผ่านข้อใดข้อหนึ่ง เช่น ตอบเป็นอังกฤษ หรืออ้างว่าทำงานนอกขอบเขตได้
   - หากยังไม่ได้ทดสอบ ให้เว้น `Actual Result` และ `Status` ว่างไว้ ไม่คาดเดาผล
6. กรอก `Notes` เป็นข้อสังเกตหรือสิ่งที่อยากลองปรับ หากยังไม่ได้ทดสอบให้ระบุสาเหตุในช่องนี้ จากนั้นเลือก `Save` เพื่อเก็บไฟล์ของตนเอง

### ตัวอย่างผลที่กรอกแล้ว — ข้อมูลสมมติ

ตัวอย่างนี้สมมติว่า Instructions กำหนดให้ Agent ช่วยจัดโน้ตและเตรียมสรุปคำขอ ให้บันทึกผลที่เกิดขึ้นกับ Agent ของตนเอง 


| ช่อง | ตัวอย่างในหนึ่งแถว |
|---|---|
| Scenario | ให้ Agent ตอบเป็นภาษาไทย |
| Starter Prompts | ทำอะไรได้บ้าง |
| Expected Result | Agent ตอบเป็นภาษาไทยและอธิบายขอบเขตงานตาม Instructions ปัจจุบัน |
| Actual Result | ตอบเป็นภาษาไทยว่า ช่วยจัดโน้ตและเตรียมสรุปคำขอได้ ตรงกับขอบเขตที่กำหนดไว้ |
| Status | Pass |
| Notes | คำตอบตรงขอบเขต แต่ค่อนข้างยาว ครั้งหน้าจะลองขอคำตอบสั้นลง |

**Checkpoint:** มีผลทดสอบหนึ่งแถวที่บันทึกจากคำตอบจริง และอธิบายได้ว่าคาดหวังอะไร เกิดอะไรขึ้น และเลือก `Pass` หรือ `Failed` เพราะอะไร หากยังทดสอบไม่ได้ ให้เว้นสถานะและระบุเหตุผลตามจริง

เมื่อต้องการทดสอบ use case ของทีม ให้ใช้แถวว่างที่พลทำไว้ กำหนด Scenario, Starter Prompts และ Expected Result ก่อนทดลอง แล้วบันทึกผลด้วยวิธีเดียวกัน หากจะนำเสนอ ใช้ [Demo run sheet](demo-run-sheet.md) เตรียมลำดับการสาธิตได้
