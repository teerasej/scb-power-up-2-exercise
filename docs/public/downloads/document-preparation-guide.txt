Fictional Training Bank — Document Preparation Guide
Training example only. Not SCB policy. Version LAB-1.

Section A: ชุดข้อมูลส่งต่อ
ใช้ Case ID และสรุปที่ไม่ระบุข้อมูลส่วนบุคคล พร้อมชนิดเอกสาร วันที่ยื่น และช่องทางถ้ามี
ข้อมูลที่ขาดต้องแยกออกจากข้อเท็จจริง

Section B: การตรวจทาน
ผู้จัดทำตรวจ Case ID และข้อเท็จจริง ผู้ตรวจทานตรวจเนื้อหาและปลายทางก่อนส่ง
ใช้เฉพาะบัญชีทดสอบที่ผู้สอนอนุญาตในชั้นเรียน

Section C: ขอบเขต
คู่มือนี้ไม่ใช่รายการเอกสารเปิดบัญชีจริง ไม่กำหนดค่าธรรมเนียม และไม่ใช้ตัดสินสิทธิ์ลูกค้า
